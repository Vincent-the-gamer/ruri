# Computer Use

Computer Use 是一项强大功能，允许 AI 智能体执行命令并与系统交互。它包含通过运行时模式、管理员权限和工作区管理的安全控制。

## 概述

启用 Computer Use 后，AI 智能体可以访问额外的工具：

- **`bash`** — 在主机系统上执行 Shell 命令
- **Python 工具** — 运行 Python 脚本
- **Shell 工具** — 增强的带工作区感知的 Shell 执行

这些工具设计用于以下场景：

- 运行构建命令和测试
- 安装依赖
- 执行脚本和程序
- 与操作系统交互

## 运行时模式

Computer Use 有三种运行时模式，控制智能体的访问级别：

| 模式       | 描述                                               |
| ---------- | -------------------------------------------------- |
| `None`     | Computer Use 已禁用；无 Shell/Python 工具可用      |
| `Local`    | 命令直接在主机系统上执行                           |
| `Sandbox`  | 命令在隔离的沙盒环境中执行                         |

### None

默认模式。`bash`、Python 和 Shell 工具对智能体不可用。这是最安全的模式，在您不需要智能体执行系统命令时推荐使用。

### Local

命令直接在主机系统上执行，具有与 Ruri 服务器进程相同的权限。这提供了完全的灵活性，但也伴随着安全考量。

::: warning
在 Local 模式下，AI 智能体可以执行 Ruri 进程有权限运行的任何命令。仅在受信任的环境中使用此模式。
:::

### Sandbox

命令在隔离环境中执行，限制了智能体的操作。这是大多数用例的推荐模式，在功能和安全之间提供平衡。

在沙盒模式下：

- 文件系统访问限制在工作区目录
- 网络访问可能受限
- 系统级命令受到限制

## 管理员权限系统

管理员权限系统控制谁可以启用或配置 Computer Use 功能：

- **管理员用户**可以更改 Computer Use 设置，包括运行时模式
- **普通用户**在启用时可以使用 Computer Use 工具，但不能更改设置
- Computer Use 模式更改需要管理员身份验证

## 工作区管理

Computer Use 在工作区上下文中运行。工作区定义了：

- **工作目录** — 命令默认执行的位置
- **允许的路径** — 智能体可以访问的目录
- **环境变量** — 执行命令时可用的变量

### 配置工作区

工作区设置可以通过以下方式配置：

- Web UI 设置页面
- [配置方案](/zh_hans/config-profiles) — 每个方案可以指定不同的工作区
- 通过 `/set` 命令设置会话变量

## 启用 Computer Use

### 通过 Web UI

1. 导航到 **设置** 页面
2. 找到 Computer Use 部分
3. 选择所需的运行时模式（Local 或 Sandbox）
4. 设置工作区目录
5. 保存配置

### 通过配置方案

在您的[配置方案](/zh_hans/config-profiles)中包含 Computer Use 设置：

```yaml
computer_use:
  enabled: true
  mode: "sandbox"
  workspace: "/path/to/workspace"
```

## 安全最佳实践

1. **尽可能使用沙盒模式** — 它提供了功能和安全性的最佳平衡
2. **限制工作区访问** — 仅允许智能体访问需要的目录
3. **监控智能体操作** — 使用[日志](#日志)功能跟踪智能体执行的命令
4. **设置管理员控制** — 确保只有受信任的用户可以启用或修改 Computer Use 设置
5. **审查工具调用** — 智能体的工具调用在对话中可见，允许您审查执行了什么

## 日志

所有 Computer Use 工具调用都通过 Ruri 的 LogManager 记录。您可以通过以下方式查看实时日志：

- **Web UI** — 日志查看器实时显示命令执行
- **WebSocket** — 连接到 `/api/ws/logs` 进行编程式日志监控
- **日志文件** — 命令记录在服务器日志文件中

这提供了对智能体在系统上所做操作的完全审计能力。
