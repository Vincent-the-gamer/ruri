# 人格系统

人格决定了 AI 是"谁" — 它的性格、说话方式和专业领域。通过切换人格，你可以让同一个 AI 变成编程专家、创意写手、或者轻松的聊天伙伴。

## 什么是人格？

每个人格包含三个要素：

- **名称** — 方便你识别，如"代码专家"
- **描述** — 简短说明这个人格的特点
- **提示词** — 定义 AI 的行为规则和沟通风格

你创建的所有人格都保存在 Ruri 中，可以随时一键切换。

## 创建你的第一个角色

![人格页面](/ruri-pics/zh_hans/personas-cn.png)

让我们创建一个"翻译助手"人格，体验人格系统的工作方式。

### 第 1 步：打开人格页面

在 Web UI 侧边栏点击 **人格**。

### 第 2 步：创建新人格

点击 **添加人格**，填写以下信息：

**名称**：`翻译助手`

**描述**：`专业中英翻译，精准传达含义`

**提示词**：

```
你是一位专业的中英双语翻译专家。你的翻译原则：

1. 准确传达原文含义，不遗漏关键信息
2. 保持原文的语气和风格（正式、口语、幽默等）
3. 对于专业术语，翻译后用括号标注原文
4. 如果原文有歧义，给出多种翻译并说明区别
5. 不添加原文没有的内容，不擅自解释

回复时直接给出翻译结果，简洁高效。
```

### 第 3 步：保存并设为活跃

点击保存，然后将该人格设为活跃人格。

### 第 4 步：体验效果

试着在聊天中发送一段英文或中文，你会发现 AI 的回复风格完全按照你定义的翻译助手人格来工作！

## 管理人格

### 通过 Web UI

1. 在侧边栏点击 **人格**
2. 查看所有已创建的人格列表
3. 点击 **添加人格** 创建新的角色
4. 点击已有的人格可进行编辑或删除
5. 一键切换活跃人格

### 切换人格

你可以通过以下方式切换人格：

- **Web UI** — 在人格页面点击激活按钮
- **配置方案** — 在[配置方案](/zh_hans/config-profiles)中指定默认人格
- **指令** — 使用 `/set persona "人格名称"` 在当前会话临时切换

## 人格与技能的关系

人格和技能协同工作，共同塑造 AI 的行为：

- **人格** — 定义 AI 的"性格"和"态度"（全局生效）
- **技能** — 定义 AI 在特定任务中的"专业知识"和"工具权限"

简单来说，人格决定 AI "怎么说"，技能决定 AI "做什么"。

::: tip
你可以为不同场景搭配不同的人格+技能组合，通过[配置方案](/zh_hans/config-profiles)一键切换。比如"编程方案"使用编程专家人格+代码审查技能，"写作方案"使用创意写手人格+文档生成技能。
:::

## 编写人格的小技巧

1. **明确角色定位** — 告诉 AI "你是谁"，它会更自然地扮演
2. **设定清晰规则** — 用编号列出行为准则，比长段落更有效
3. **界定边界** — 说明 AI 应该做什么、不应该做什么
4. **给出回复风格** — 如"简洁"或"详细"，让 AI 回复更符合期望
5. **多试多调** — 根据实际对话效果不断优化提示词
