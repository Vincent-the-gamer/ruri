# 人格系统

人格定义了 AI 助手的性格和行为方式。每个人格都有一个名称、描述和系统提示词，决定了 AI 如何响应消息。

## 概述

通过人格系统，您可以为不同用例创建多个 AI 人格：

- **编程助手**人格 — 专注于技术准确性
- **创意写手**人格 — 具有更具表现力的语气
- **导师**人格 — 逐步解释概念
- **简洁应答者**人格 — 给出简明扼要的答复

## 人格结构

每个人格由以下部分组成：

| 字段          | 类型   | 描述                                     |
| ------------- | ------ | ---------------------------------------- |
| `name`        | string | 人格的唯一名称                           |
| `description` | string | 人格风格/角色的简短描述                  |
| `prompt`      | string | 定义人格行为的系统提示词                  |

**示例人格：**

```yaml
name: "代码专家"
description: "一位资深软件工程师，提供精确、文档完善的代码解决方案"
prompt: |
  你是一位拥有 20 年经验的资深软件工程师。
  编写代码时，你始终：
  - 包含适当的错误处理
  - 添加清晰的注释和文档
  - 遵循语言特定的最佳实践和约定
  - 为关键逻辑建议测试
  保持解释简洁，专注于代码质量。
```

## 管理人格

### 通过 Web UI

1. 在侧边栏中导航到 **人格** 页面
2. 查看现有人格列表
3. 通过填写名称、描述和提示词创建新人格
4. 编辑现有人格以优化其行为
5. 删除不再需要的人格
6. 将人格设置为当前会话的活跃人格

### 活跃人格

活跃人格应用于所有对话。您可以随时更改活跃人格：

- 通过 Web UI
- 通过[配置方案](/zh_hans/config-profiles) — 每个方案可以指定默认人格
- 通过[指令系统](/zh_hans/commands) — 使用 `/set` 更改当前会话的人格

## 人格与技能

人格和技能协同工作，提供完整的 AI 行为：

- **人格**定义了 AI 的总体语气和行为
- **技能**定义了具有工具访问控制的特定任务或行为

当技能指定了 `model` 或使用自己的提示词时，它可能会在该特定技能执行期间覆盖活跃人格。否则，使用活跃人格作为基础系统提示词。

## 编写有效人格的技巧

1. **要具体** — 明确定义人格的角色、专业领域和沟通风格
2. **设定边界** — 指定人格应该和不应该做的事情
3. **包含示例** — 在提示词中展示期望的响应格式
4. **保持专注** — 避免在同一个人格中包含冲突的指令
5. **测试和迭代** — 根据 AI 的实际响应优化您的人格

::: tip
您可以创建多个用于不同场景的人格，使用[配置方案](/zh_hans/config-profiles)在它们之间切换。这样您无需重写提示词即可快速调整 AI 的行为。
:::
