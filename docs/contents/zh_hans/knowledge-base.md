# 知识库

Ruri 包含一个基于 RAG（检索增强生成）的知识库系统，允许 AI 智能体在对话过程中引用和搜索您的文档。

## 概述

知识库系统的工作流程：

1. **导入**各种格式的文档
2. **分块**将文档分割为可管理的片段
3. **嵌入**使用嵌入模型将分块转换为向量
4. **存储**将嵌入向量存入向量数据库
5. **搜索**当收到查询时搜索相关分块
6. **重排序**对结果进行重排序以提高相关性

这使得 AI 智能体可以基于您的特定文档和数据回答问题，而不仅仅依赖其训练数据。

## 支持的文档格式

| 格式       | 扩展名            | 描述                     |
| ---------- | ----------------- | ------------------------ |
| PDF        | `.pdf`            | Adobe PDF 文档           |
| Excel      | `.xls`, `.xlsx`   | Microsoft Excel 电子表格  |
| DOCX       | `.docx`           | Microsoft Word 文档      |
| 纯文本     | `.txt`, `.md`     | 纯文本和 Markdown 文件   |

## 配置

### 嵌入模型

嵌入模型将文本转换为向量表示，用于语义搜索。您需要配置：

- 嵌入模型提供商和端点
- 模型标识符
- API 密钥（如需要）
- 嵌入维度

### 重排序模型

重排序模型通过重新评分和重新排列最初检索到的分块来改善搜索结果。这是可选但推荐的步骤，可提高准确性。

**配置字段：**

| 字段       | 描述                                   |
| ---------- | -------------------------------------- |
| 提供商     | 重排序模型提供商                       |
| API URL    | 重排序服务的端点                       |
| API Key    | 身份验证密钥                           |
| 模型       | 重排序模型标识符                       |
| Top-K      | 重排序后返回的顶部结果数量             |

### 分块配置

文档在嵌入之前被分割成块。您可以配置：

| 参数         | 描述                                   |
| ------------ | -------------------------------------- |
| 分块大小     | 每个块的最大 token 数量                |
| 分块重叠     | 块之间重叠的 token 数量                |
| 分隔符       | 用于分割的文本分隔符                   |

## 处理流程

知识库流程将文档通过以下阶段处理：

```
文档 → 解析 → 分块 → 嵌入 → 存储
                                    ↓
查询 → 嵌入查询 → 向量搜索 → 重排序 → 上下文
```

### 1. 文档解析

文档从原始格式解析为纯文本。每种格式都有专用的解析器：

- **PDF**：从 PDF 页面提取文本内容
- **Excel**：从电子表格工作表读取单元格数据
- **DOCX**：从 Word 文档提取文本和格式
- **纯文本**：直接读取内容

### 2. 分块

解析后的文本被分割成重叠的块。分块参数控制这些片段的大小和重叠，在粒度和上下文保留之间取得平衡。

### 3. 嵌入

每个块通过嵌入模型处理以产生向量表示。这些向量捕获文本的语义含义，实现基于相似度的搜索。

### 4. 存储

嵌入向量与原始文本块和元数据一起存储在向量数据库中。

### 5. 搜索

当收到查询时：

1. 使用相同的嵌入模型对查询进行嵌入
2. 向量相似度搜索找到最相关的块
3. 可选地使用重排序模型对结果进行重排序
4. 排名最高的块作为上下文提供给 AI 模型

## 管理知识库

### 通过 Web UI

1. 导航到 **知识库** 页面
2. 创建新的知识库，输入名称和描述
3. 上传文档到知识库
4. 监控导入进度
5. 激活或停用知识库

### 激活知识库

知识库必须被激活才能在对话中使用。您可以通过以下方式激活知识库：

- Web UI
- [配置方案](/zh_hans/config-profiles) — 每个方案指定哪些知识库处于活跃状态

当知识库处于活跃状态时，AI 智能体会在收到相关查询时自动搜索它。

## 性能提示

- **使用高质量的嵌入模型** — 更好的嵌入会带来更准确的搜索结果
- **启用重排序** — 重排序可显著提高结果相关性
- **调整分块大小** — 较小的块更精确但可能丢失上下文；较大的块保留上下文但可能引入噪声
- **使用重叠** — 重叠的块有助于在块边界处保留信息
- **保持知识库聚焦** — 针对特定领域的知识库比通用知识库表现更好
