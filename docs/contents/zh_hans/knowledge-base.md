# 知识库

知识库让 AI 能够基于**你自己的文档**来回答问题，而不仅仅依赖它训练时的知识。上传你的文档，AI 就能在对话中引用文档内容，给出更准确、更相关的回答。

## 为什么需要知识库？

AI 模型的知识有截止日期，而且不知道你团队内部的资料。知识库解决了这个问题：

- 📄 **内部文档查询** — 上传公司规范、项目文档，AI 就能基于它们回答
- 📊 **数据分析** — 上传 Excel 表格，AI 可以帮你查找和分析数据
- 📚 **学习资料** — 上传课件、论文，AI 基于资料帮你答疑
- 🔍 **精准回答** — AI 的回答会有文档依据，不再"凭空编造"

## 支持的文件格式

| 格式  | 扩展名          | 说明              |
| ----- | --------------- | ----------------- |
| PDF   | `.pdf`          | PDF 文档          |
| Excel | `.xls`, `.xlsx` | 电子表格          |
| Word  | `.docx`         | Word 文档         |
| 文本  | `.txt`, `.md`   | 纯文本和 Markdown |

## 知识库入门

### 第 1 步：创建知识库

1. 在侧边栏点击 **知识库**
2. 点击 **新建知识库**
3. 输入名称和描述（如"项目文档"、"学习资料"）
4. 保存

### 第 2 步：上传文档

1. 进入你创建的知识库
2. 点击 **上传文档**
3. 选择文件上传
4. 等待处理完成

::: info
文档处理需要一些时间，取决于文件大小和数量。AI 会自动将文档分块、建立索引，方便后续快速检索。
:::

### 第 3 步：激活知识库

知识库必须激活才能在对话中使用：

1. 在知识库列表中，点击 **激活** 按钮
2. 激活后，AI 在收到相关问题时会自动搜索知识库

你也可以在[配置方案](/zh_hans/config-profiles)中指定哪些知识库处于活跃状态。

### 第 4 步：开始使用

现在你可以在对话中提问了！例如：

- "根据我上传的项目文档，API 的认证方式是什么？"
- "帮我查一下员工手册中关于假期的规定"
- "总结一下这份 PDF 的核心内容"

AI 会自动搜索知识库中的相关内容，然后基于文档给你回答。

## 嵌入模型配置

知识库需要嵌入模型来理解文档内容。首次使用知识库功能时，你需要在设置中配置嵌入模型：

- **嵌入模型提供商** — 选择一个提供商（支持 OpenAI 兼容和 Anthropic 兼容格式）
- **模型名称** — 如 `text-embedding-3-small`（OpenAI）或你的嵌入模型名称
- **API URL** — 嵌入服务的端点地址
- **API Key** — 服务的访问密钥

::: tip
如果你使用 OpenAI，嵌入模型推荐 `text-embedding-3-small`，性价比高且效果好。
:::

## 重排序模型（可选）

重排序模型可以显著提升搜索质量。启用后，AI 会先做初步搜索，再对结果做二次排序，确保最相关的内容排在最前面。

你可以在知识库设置中配置重排序模型，但这是可选项 — 不配置也能正常使用知识库。

## 管理知识库

在知识库页面，你可以：

- 📋 查看所有知识库及其状态
- 📤 继续上传新文档
- 🔄 重新处理文档（更新索引）
- ✅ 激活或停用知识库
- 🗑️ 删除不再需要的知识库

## 性能优化建议

- 🎯 **知识库聚焦** — 按主题创建不同的知识库，比把所有文档放进一个库效果更好
- 📝 **文档质量** — 文本清晰的文档比扫描件效果更好
- 🔍 **启用重排序** — 如果发现 AI 的回答引用了不太相关的内容，试试启用重排序模型
- 📏 **适当分块** — 如果你了解技术细节，可以调整分块大小来优化检索效果
