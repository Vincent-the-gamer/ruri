# 快速开始

欢迎使用 **Ruri 琉璃** 🎉 — 你的专属 AI 助手平台！只需要一个浏览器，就能拥有一个功能强大的 AI 智能体。

## Ruri 能做什么？

- 💬 **智能对话** — 和 AI 自由聊天，它懂代码、懂写作、懂翻译……
- 📁 **文件操作** — AI 可以帮你读写文件、搜索代码、整理项目
- 🔍 **联网搜索** — 遇到不知道的问题？AI 可以直接搜索网络
- 🛠️ **技能扩展** — 用 Markdown 就能创建自定义技能，让 AI 按你的方式工作
- 🎭 **角色切换** — 一键切换 AI 人格：编程专家、创意写手、翻译助手……
- 📚 **知识库** — 上传你的文档，AI 就能基于你的资料回答问题
- 🤖 **多平台聊天** — 在钉钉、Discord、微信中也能和 AI 对话
- 🖥️ **IDE 集成** — 在 Zed、JetBrains 等 IDE 中使用 Ruri

听起来很棒？让我们开始吧！

## 安装

### 第 1 步：下载 Ruri

前往 [GitHub Releases](https://github.com/Vincent-the-gamer/ruri/releases) 下载适合你操作系统的最新版本。

### 第 2 步：配置环境

将下载的二进制文件添加到你的系统环境变量 `PATH` 中，这样你可以在任何终端位置运行 `ruri` 命令。

### 第 3 步：启动 Ruri

在终端中运行：

```bash
# 查看帮助
ruri -h

# 默认端口： 3000
ruri
# 指定端口
ruri --port 8080
# 远程访问，将端口暴露在局域网
ruri --remote
```

这将同时启动后端服务和 Web UI。

### 第 4 步：登录

在浏览器中打开：

```
http://localhost:3000
```

首次登录的默认凭据：

| 字段   | 默认值 |
| ------ | ------ |
| 用户名 | `ruri` |
| 密码   | `ruri` |

::: warning
首次登录后，系统会提示你修改密码。请务必设置一个安全的新密码！
:::

### 第 5 步：配置模型提供商

登录后，你需要至少配置一个 AI 模型提供商才能开始对话：

1. 在侧边栏点击 **提供商**
2. 点击 **添加提供商**
3. 填写你的 API 信息（参考[模型提供商](/zh_hans/providers)页面中的快速配置指南）
4. 点击 **激活** 该提供商

完成后，你就可以开始和 AI 聊天了！🎉

## 常见问题

### 启动后无法访问 `http://localhost:3000`

- 检查终端是否显示服务已成功启动
- 确认 3000 端口没有被其他程序占用
- 尝试使用 `http://127.0.0.1:3000` 访问

### 登录时提示密码错误

- 请确认使用默认凭据：用户名 `ruri`，密码 `ruri`
- 如果你已修改过密码，请使用新密码

### 配置提供商后 AI 不回复

- 确认提供商已被激活（显示激活状态）
- 检查 API Key 是否正确
- 检查 API URL 是否包含正确的路径（如 OpenAI 兼容需要 `/v1` 后缀）
- 查看[模型提供商](/zh_hans/providers)中的快速配置指南

### 找不到 Ruri 命令

- 确认已将 Ruri 添加到系统 `PATH` 中
- 尝试重启终端
- 使用完整路径运行：`/path/to/ruri`
