# 配置方案

配置方案允许您创建和切换不同的配置预设。每个方案定义了一组完整的设置，决定了 AI 智能体的行为方式。

## 概述

无需每次手动更改个别设置来使智能体行为不同，您可以创建多个方案并即时切换。这在您将 Ruri 用于不同目的时特别有用。

**示例场景：**

- **编程**方案 — 技术人格、文件工具和沙盒模式
- **写作**方案 — 创意人格和启用网页搜索
- **研究**方案 — 知识库访问和网页搜索
- **平台**方案 — 聊天平台集成活跃

## 方案结构

每个配置方案包含以下设置：

| 字段                     | 类型    | 描述                                                    |
| ------------------------ | ------- | ------------------------------------------------------- |
| `provider`               | string  | 活跃的模型提供商                                        |
| `persona`                | string  | 活跃的人格                                              |
| `web_search`             | boolean | 启用或禁用网页搜索                                      |
| `computer_use`           | boolean | 启用或禁用 Computer Use                                 |
| `computer_use_mode`      | string  | Computer Use 运行时模式（`none`、`local`、`sandbox`）   |
| `acp`                    | boolean | 启用或禁用 ACP 服务器                                   |
| `active_skills`          | array   | 此方案中启用的技能列表                                  |
| `active_platforms`       | array   | 此方案中启用的平台列表                                  |
| `active_knowledge_bases` | array   | 此方案中启用的知识库列表                                |
| `proxy`                  | object  | 网络请求的代理配置                                      |
| `command_prefix`         | string  | 指令识别的前缀（默认：`/`）                             |

## 管理方案

### 通过 Web UI

1. 导航到 **设置** 或 **配置方案** 页面
2. 查看现有方案
3. 使用所需设置创建新方案
4. 即时切换方案
5. 编辑或删除方案

### 方案切换

当您切换方案时，方案中的所有设置会立即应用：

- 模型提供商变更
- 人格切换
- 工具和技能相应地启用/禁用
- 平台连接更新
- 知识库访问调整

## 方案配置详情

### 提供商

选择方案激活时使用的模型提供商。该提供商必须已在[模型提供商](/zh_hans/providers)中配置。

### 人格

选择方案的默认[人格](/zh_hans/personas)。这决定了 AI 的性格和沟通风格。

### 网页搜索

启用后，`web_search` 工具对 AI 智能体可用。您还需要配置搜索提供商设置。

### Computer Use

启用后，智能体可以执行系统命令。您可以指定运行时模式：

- `none` — 已禁用
- `local` — 命令在主机系统上运行
- `sandbox` — 命令在沙盒环境中运行

更多详情请参阅 [Computer Use](/zh_hans/computer-use)。

### ACP

为此方案启用或禁用 [ACP 服务器](/zh_hans/acp)。当 ACP 服务器运行时，外部 IDE 客户端可以将 Ruri 作为智能体服务器连接。

### 活跃技能

指定此方案中可用的[技能](/zh_hans/skills)。仅列出的技能在方案使用时处于活跃状态。

### 活跃平台

指定此方案中连接的[聊天平台](/zh_hans/platforms)。这允许您创建仅使用特定消息服务的方案。

### 活跃知识库

指定此方案中可用于 RAG 查询的[知识库](/zh_hans/knowledge-base)。

### 代理

为出站请求（API 调用、网页搜索等）配置网络代理设置：

```yaml
proxy:
  enabled: true
  url: "http://proxy.example.com:8080"
  no_proxy:
    - "localhost"
    - "127.0.0.1"
```

### 指令前缀

自定义用于识别[指令](/zh_hans/commands)的前缀。默认为 `/`。

## 使用技巧

- **从默认方案开始** — 首先创建一个通用方案，然后为特定用例创建专用方案
- **使用描述性名称** — 根据方案目的命名（如"编程"、"研究"、"休闲聊天"）
- **测试新设置** — 在尝试新配置时创建测试方案
- **保持方案聚焦** — 方案应服务于特定目的，而不是试图兼顾一切
