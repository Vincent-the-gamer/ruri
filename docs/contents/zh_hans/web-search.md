# 网页搜索

网页搜索功能允许 AI 从互联网上查找最新信息。当你需要了解近期事件、当前文档版本，或任何可能不在 AI 训练数据中的信息时，这个功能非常有用。

## 为什么使用网页搜索？

默认情况下，AI 依赖于其训练数据，而训练数据存在知识截止日期。启用网页搜索后，AI 可以：

- **查找当前信息** — 搜索最新新闻、价格或事件
- **访问最新文档** — 查找最新的 API 文档或教程
- **验证事实** — 交叉引用信息以确保准确性
- **发现新资源** — 查找最近发布的工具、库或服务

## 启用网页搜索

![网页搜索设置](/ruri-pics/zh_hans/web-search-cn.png)

### 第 1 步：配置网页搜索设置

1. 在侧边栏进入 **网页搜索**
2. 选择搜索引擎（见下方选项）
3. 如果需要，输入 API 密钥
4. 设置最大结果数量（默认：10）
5. 将网页搜索切换为 **开启**
6. 保存配置

### 第 2 步：在配置方案中启用

网页搜索可以通过 [配置方案](/zh_hans/config-profiles) 进行控制。确保在你使用的方案中已启用。

## 支持的搜索引擎

| 引擎             | 需要 API 密钥 | 说明                                   |
| ---------------- | ------------- | -------------------------------------- |
| **DuckDuckGo**   | 否            | 免费且注重隐私的搜索引擎，无需额外设置 |
| **Tavily**       | 是            | 专为 AI 智能体设计的搜索引擎           |
| **博查 (BoCha)** | 否            | 针对中文内容优化的搜索引擎             |
| **百度 (Baidu)** | 否            | 中国最大的搜索引擎                     |
| **Brave**        | 是            | 注重隐私的搜索引擎                     |

### DuckDuckGo（推荐快速开始）

DuckDuckGo 是最简单的选项 — 无需 API 密钥，只需开启网页搜索即可使用。

### Tavily

Tavily 专为 AI 智能体设计，提供高质量的结果：

1. 在 [tavily.com](https://tavily.com/) 注册获取 API 密钥
2. 在网页搜索设置中输入 API 密钥
3. Tavily 提供免费额度，每月有限次查询

### 博查和百度

这些引擎在搜索中文内容或来自中国来源的信息时推荐使用。

### Brave Search

Brave Search 提供注重隐私的搜索结果：

1. 在 [brave.com/search/api](https://brave.com/search/api/) 注册获取 API 密钥
2. 在网页搜索设置中输入 API 密钥

## 工作原理

启用网页搜索后，AI 会在你的问题需要当前信息时自动决定搜索网络。你会看到以下流程：

1. **你提出问题** — 例如 "React 最新版本是什么？"
2. **AI 决定搜索** — 工具调用显示搜索查询
3. **返回搜索结果** — AI 阅读搜索结果
4. **AI 回复** — 使用搜索结果给出有根据的回答

::: tip
你不需要告诉 AI 去搜索 — 它会自动判断何时需要网络信息。
:::

## 实用示例

### 时事新闻

```
用户："最近的科技大会发生了什么？"
AI：[搜索网络] → 返回关于该活动的最新新闻
```

### 软件版本

```
用户："Rust 的最新稳定版本是什么？"
AI：[搜索网络] → 返回当前版本号和发布日期
```

### 故障排除

```
用户："我遇到了这个错误：[错误信息]"
AI：[搜索该错误] → 找到相关的解决方案和变通方法
```

### 研究

```
用户："2024 年微服务的最佳实践是什么？"
AI：[搜索最新文章] → 总结当前的最佳实践
```

## 管理网页搜索

### 通过 Web UI

1. 在侧边栏进入 **网页搜索**
2. **切换** 网页搜索开关
3. **更改** 搜索引擎
4. **更新** API 密钥或其他设置
5. **调整** 最大结果数量

### 按方案控制

使用 [配置方案](/zh_hans/config-profiles) 在不同场景下控制网页搜索：

- **编程方案** — 启用网页搜索以查找文档
- **闲聊方案** — 关闭网页搜索以获得更快的响应
- **研究方案** — 启用网页搜索并使用 Tavily 获取高质量结果

## 使用建议

- **从 DuckDuckGo 开始** — 无需设置，适用于大多数情况
- **使用 Tavily 获得更好质量** — 如果需要更准确和相关的结果
- **监控 API 使用情况** — 部分搜索引擎在免费额度上有查询限制
- **配合知识库使用** — 将网页搜索与 [知识库](/zh_hans/knowledge-base) 结合使用效果最佳
- **调整最大结果数** — 更多结果 = 更好的覆盖范围但响应更慢。从默认值（10）开始，根据需要调整
