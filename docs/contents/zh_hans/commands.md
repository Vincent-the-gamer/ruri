# 指令系统

Ruri 提供了一系列便捷的聊天指令，你可以直接在消息输入框中输入。它们以 `/` 开头，让你能快速掌控当前会话。

## 快速参考

| 指令                 | 作用                          |
| -------------------- | ----------------------------- |
| `/help`              | 显示可用指令和版本信息        |
| `/new`               | 开始一个全新的对话            |
| `/reset`             | 清除当前对话中 AI 的记忆      |
| `/sid`               | 显示当前会话信息              |
| `/whoami`            | 显示用户 ID、身份和管理员状态 |
| `/set <key> <value>` | 修改当前对话的某项设置        |
| `/unset <key>`       | 移除之前设置的某项配置        |
| `/stop`              | 当 AI 耗时过长时停止它        |
| `/dashboard_update`  | 更新 Web UI（仅管理员）       |

## 指令详解

### `/help` — 获取帮助

显示所有可用指令以及当前 Ruri 版本。

```
/help
```

### `/new` — 新建对话

创建一个全新的对话并切换到它。当你想要一个完全干净的起点时使用。

```
/new
```

::: tip
切换话题时使用 `/new`，可以防止 AI 被之前的对话上下文干扰。
:::

### `/reset` — 重置上下文

清除 AI 记忆中的对话历史，但保留在当前对话中。可以理解为"忘掉我们刚才聊的内容"，而无需开启一个全新的对话。

以下情况适合使用 `/reset`：

- 对话变得很长，AI 的回复开始不对劲
- 你想在同一个对话中更改话题
- AI 似乎被之前的消息搞混了

```
/reset
```

::: tip
`/new` 会创建一个全新的对话，而 `/reset` 只清除当前对话中的上下文。想完全重新开始时用 `/new`，只想换个方向时用 `/reset`。
:::

### `/sid` — 会话信息

显示当前会话的相关信息。

```
/sid
```

### `/whoami` — 我是谁

显示你的用户 ID、当前平台、消息类型以及是否拥有管理员权限。在排查权限问题时很有用。

```
/whoami
```

::: tip
WebUI 用户始终被视为管理员（已通过认证）。如果你使用的是聊天平台（钉钉、Discord 等），管理员状态取决于你的用户 ID 是否在 Computer Use 设置的管理员列表中。
:::

### `/set` — 修改设置

修改当前对话的某项设置。常见用法：

```
/set persona "Code Expert"
/set model "gpt-4o"
/set effort high
```

这些更改仅对当前对话生效 — 开始新对话后会重置。

### `/unset` — 移除设置

移除之前用 `/set` 设置的配置：

```
/unset persona
```

### `/stop` — 停止 AI

如果 AI 耗时过长、做了意料之外的事或陷入循环，使用 `/stop` 立即中断它。

```
/stop
```

::: tip
AI 的回复有时需要一些时间，尤其是涉及复杂工具调用时。在停止之前给它一点时间 — 但如果确实不对劲，不要犹豫使用 `/stop`。
:::

### `/dashboard_update` — 更新 Web UI

触发 Web UI 的更新。此指令需要管理员权限。

```
/dashboard_update
```

## 实用示例

### 切换人格

```
/set persona "Casual Chat"
```

AI 会在当前对话的后续回复中立即切换为更轻松、友好的语气。

### 使用不同的模型

```
/set model "claude-sonnet-4-20250514"
```

为当前对话切换到另一个模型。请确保该模型在你当前激活的提供商中可用。

### 获得更优质的分析

```
/set effort high
```

告诉 AI 更仔细地思考并给出更详尽的回复。

### 快速重置上下文

```
/reset
```

AI 会忘记当前对话的上下文，让你无需创建新对话即可开始一个新话题。

## 须知事项

- 指令在消息发送给 AI **之前**就已处理 — 它们即刻生效
- 指令**不会**发送给 AI 模型，因此 AI 不会在对话中看到它们
- 如果你想让 AI 知道某项设置变更，请在普通消息中提及（例如："顺便说一下，我已经把你切换到了高投入模式"）
- 所有 `/set` 的更改都是临时的 — 开始新对话后即重置
