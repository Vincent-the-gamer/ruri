# 指令系统

Ruri 包含一个内置指令系统，允许您直接从聊天输入与智能体交互并管理会话。指令以 `/` 为前缀，提供对常用操作的快速访问。

## 可用指令

| 指令                  | 描述                                   |
| --------------------- | -------------------------------------- |
| `/help`               | 显示可用指令和版本信息                 |
| `/sid`                | 显示当前会话信息                       |
| `/reset`              | 重置当前对话的 LLM 上下文              |
| `/new`                | 创建并切换到新对话                     |
| `/set <key> <value>`  | 设置会话变量                           |
| `/unset <key>`        | 移除会话变量                           |
| `/stop`               | 停止当前运行的智能体任务               |
| `/dashboard_update`   | 更新 WebUI（需要管理员权限）           |

## 指令详情

### `/help`

显示所有可用指令列表以及当前 Ruri 版本信息。

```
/help
```

### `/sid`

显示当前会话的信息，包括会话 ID 和活跃配置。

```
/sid
```

### `/reset`

重置当前对话的 LLM 上下文。这会清除模型记忆中的对话历史，有效地重新开始一个干净的上下文，同时保留对话容器。

适用场景：
- 对话上下文变得过长，响应质量下降
- 想在同一对话中开始新话题
- 模型似乎被之前的消息混淆

```
/reset
```

### `/new`

创建一个新对话并切换到该对话。当您想以全新的状态开始完全新的对话时非常有用。

```
/new
```

### `/set <key> <value>`

设置在当前对话期间持久存在的会话变量。会话变量可用于动态配置智能体行为。

```
/set persona "代码专家"
/set model "gpt-4o"
/set effort high
```

### `/unset <key>`

移除之前设置的会话变量。

```
/unset persona
```

### `/stop`

停止当前运行的智能体任务。这在以下场景中非常有用：
- 智能体响应时间过长
- 智能体正在执行不希望的操作
- 想中断长时间运行的工具调用链

```
/stop
```

### `/dashboard_update`

触发 Web UI 的更新。此命令需要管理员权限。

```
/dashboard_update
```

## 使用指令

指令可以直接在聊天输入框中输入。它们在消息发送给 AI 模型之前被处理，因此立即执行而不涉及模型。

::: tip
指令不会发送给 AI 模型。它们由 Ruri 服务器本地处理。如果您希望模型知道您所做的配置更改，请在普通消息中提及。
:::

## 编程方式访问

也可以通过聊天 API 触发指令，将指令作为消息内容包含：

```bash
curl -X POST http://localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -H "Cookie: session=<your-session-cookie>" \
  -d '{"message": "/new"}'
```
