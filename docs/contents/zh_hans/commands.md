# 指令系统

指令是 Ruri 中的快捷操作 — 在聊天输入框中以 `/` 开头即可执行。指令不会发送给 AI，而是由 Ruri 直接处理，立即生效。

## 指令一览

| 指令                 | 作用               | 常用场景                        |
| -------------------- | ------------------ | ------------------------------- |
| `/help`              | 显示帮助和版本信息 | 忘记有哪些指令时使用            |
| `/new`               | 创建新对话         | 想开始一个全新话题时            |
| `/reset`             | 重置当前对话上下文 | 对话太长导致 AI 回复变差时      |
| `/stop`              | 停止当前 AI 任务   | AI 回复太久或做了不想做的操作时 |
| `/set <key> <value>` | 设置会话变量       | 临时切换人格或模型时            |
| `/unset <key>`       | 移除会话变量       | 取消之前的设置                  |
| `/sid`               | 显示当前会话信息   | 查看会话 ID 等信息              |
| `/dashboard_update`  | 更新 Web UI        | 需要 Web UI 更新时（管理员）    |

## 指令详解

### `/new` — 开启新对话

创建一个全新的对话并自动切换过去。适用于想要一个干净的新起点时。

**示例：**

```
/new
```

### `/reset` — 重置对话上下文

清除 AI 的对话记忆，但保留当前对话。适用于以下情况：

- 对话太长，AI 开始"忘记"之前说的内容
- 想在同个对话中切换到完全不同的话题
- AI 的回复质量下降

**示例：**

```
/reset
```

::: tip
`/reset` 和 `/new` 的区别：`/reset` 清除记忆但留在当前对话，`/new` 是打开一个全新的对话。
:::

### `/stop` — 停止 AI 任务

当 AI 正在执行耗时操作（如搜索多个文件、运行长命令），你想中断时使用。

**示例：**

```
/stop
```

### `/set` — 临时改变设置

在当前会话中临时更改配置，不影响其他对话。

**实用示例：**

| 操作         | 指令                      |
| ------------ | ------------------------- |
| 临时切换人格 | `/set persona "创意写手"` |
| 临时切换模型 | `/set model "gpt-4o"`     |
| 调整推理力度 | `/set effort high`        |

### `/unset` — 取消临时设置

移除之前用 `/set` 设置的会话变量。

**示例：**

```
/unset persona
```

### `/help` — 查看帮助

显示所有可用指令和 Ruri 版本信息。

### `/sid` — 查看会话信息

显示当前会话的 ID 和活跃配置信息。

### `/dashboard_update` — 更新 Web UI

触发 Web UI 更新。需要管理员权限。

## 使用技巧

- 📝 指令只影响当前会话，不会修改全局设置
- 🔄 搭配 `/set` 和 `/unset` 可以在对话中灵活调整行为
- ⏹️ 当 AI 执行了你不期望的操作，立即用 `/stop` 中断
- 🧹 当对话变长时，试着用 `/reset` 优化 AI 的回复质量

::: tip
指令由 Ruri 服务器处理，不会发送给 AI 模型。如果你希望 AI 知道某个配置变化，请在普通消息中告诉它。
:::
