# 开发者指南

欢迎使用 **Ruri 琉璃** 开发者指南！本章节面向希望基于 Ruri 进行开发、将其集成到自己的应用中，或为项目贡献代码的开发者。

## 本章节内容

| 页面 | 描述 |
| --- | --- |
| [快速开始](/zh_hans/dev/getting-started) | 搭建开发环境、从源码构建，以及了解项目结构 |
| [API 使用指南](/zh_hans/dev/api-usage) | 以编程方式使用 Ruri REST API 的实用指南——认证、常用模式、代码示例和错误处理 |
| [集成指南](/zh_hans/dev/integration) | 将 Ruri 集成到你的应用中——REST API、IDE 的 ACP 集成、MCP 服务器开发、Webhook 和自定义聊天客户端 |

## 适合谁？

- **应用开发者** — 希望构建与 Ruri 编程交互的工具或服务
- **IDE 插件开发者** — 希望将 Ruri 集成为 AI 编码助手
- **平台集成者** — 希望将 Ruri 扩展到新的聊天平台或服务
- **代码贡献者** — 希望理解代码库并提交补丁
